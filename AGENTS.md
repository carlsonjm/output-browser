# Agent instructions

## Startup

1. Read `AGENTS.md` and `README.md`.
2. The plan, design approval, test results and cross-repository dependencies
   belong to the suite record, kept privately with the Shuffle repository. Say
   so when it is not at hand.

## Rules

- This repository is public. Its documents, code comments and commit messages
  describe the software in the present tense. They carry no names, approvals or
  approval dates, and no chat or handover narration. Planned behaviour is kept
  privately, never here.
- CEF is used as its makers publish it, built with the GN settings in
  `tools/build-cef.sh`. A change to Chromium or CEF source is a fork and is
  not made here.
- Code comments explain code behaviour or reasoning only.
- Never rewrite history already merged to `main`.
